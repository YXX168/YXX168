## 关于我

- 偏爱 **本地优先 / 自托管**：数据不上传，功能不依赖云端账号
- 视觉上痴迷 **玻璃态与霓虹**，动效是刚需，不是装饰
- 主力 Flutter / Dart 做 Android 应用，也写 TypeScript、Go、CSS
- 喜欢单文件、开箱即用的东西，讨厌为了跑起来先配半小时环境
